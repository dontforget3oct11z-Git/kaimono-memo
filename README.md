# ふたりの買い物メモ（Firebase版）

アカウント登録なしで使える、夫婦で共有する買い物メモです。
最初の一人がアプリを開くと専用のリストが作られ、その「共有リンク」を送るだけでパートナーも同じリストを使えます。

- 追加・チェック・削除がふたりの画面にすぐ反映されます
- 電波の悪いお店の中でも操作でき、つながったときに送信されます
- ホーム画面に追加するとアプリのように使えます
- **いつも買うもの**：追加するときに「毎週」「2週ごと」「毎月」を選ぶと登録され、買ってリストから消すと、次の時期に自動でリストに戻ります
  - 頻度はあとから「いつも買うもの」欄で変えられます。「今すぐ追加」で前倒しも可能
  - リスト上の × は「今回は買わない」の意味で、次の時期にまた入ります。登録をやめるときは「いつも買うもの」欄の ×
- **お店のお得日**：トモズのポイントアップデーなどを毎朝自動で取り込み、「今日」と近日のお得日を表示します。自動で取り込めないお店は「＋ 手で追加」から「毎月5日・15日」や日付指定で登録できます
- **今回だけ買うもの**：買ってリストから消すと「最近買ったもの」に並び、ワンタップで追加し直せます

費用：Firebase の無料プラン（Spark）の範囲で収まります。クレジットカードの登録は不要です。

## 準備（金城さんが最初に1回だけ）

### 1. Firebase プロジェクトを作る（約5分）
1. https://console.firebase.google.com を Google アカウントで開く
2. 「プロジェクトを作成」→ 名前は `kaimono-memo` など何でもOK → Google アナリティクスは「オフ」でOK
3. 左メニュー「構築」→「Authentication」→「始める」→「ログイン方法」タブで **匿名** を選んで「有効にする」→ 保存
4. 左メニュー「構築」→「Firestore Database」→「データベースを作成」
   - ロケーション：`asia-northeast1（東京）`
   - 「本番環境モードで開始」を選ぶ
5. Firestore の「ルール」タブを開き、中身をすべて `firestore.rules` の内容に置き換えて「公開」
6. 歯車アイコン「プロジェクトの設定」→ 下の「マイアプリ」で `</>`（ウェブ）を押す → ニックネームを入れて「アプリを登録」
   - 表示される `firebaseConfig = { ... }` の中身（apiKey, authDomain, projectId など）をコピーして Claude に送る
   - この値は公開しても問題ない種類のものです（パスワードではありません）

### 2. 公開する（GitHub Pages、無料）
1. GitHub で新しいリポジトリを **Public** で作成（例：`kaimono-memo`）
2. このフォルダのファイル（index.html, manifest.webmanifest, icon.svg, icon-*.png）をアップロード
   （Claude にリポジトリを接続してもらえれば、こちらで置きます）
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後に `https://<GitHubユーザー名>.github.io/kaimono-memo/` で開けます
5. Firebase の Authentication →「設定」→「承認済みドメイン」に `<GitHubユーザー名>.github.io` を追加

### 3. ふたりで使い始める
1. 金城さんのスマホで公開URLを開く → 自動で新しいリストができ、「パートナーと共有する」欄に共有リンクが出ます
2. 「コピー」を押して LINE などでパートナーに送る
3. パートナーがそのリンクを開けば完了。以後は同じリストが表示されます
4. それぞれ「ホーム画面に追加」しておくと便利です（iPhone は Safari の共有ボタン →「ホーム画面に追加」）

共有リンクはあとからでも、画面下の「共有リンクを表示」で確認できます。

## 安全性について
- リストの中身は、共有リンク（32文字のランダムなID入り）を知っている人だけが見られます
- 逆に言えば、リンクを知っている人は誰でも編集できるので、ふたり以外には送らないでください

## お店のお得日の自動取り込み

- 取り込むお店は `stores.json` に書きます。`source` は読み取り方法の名前で、今は `tomods`（トモズ各店の「お知らせ」）に対応しています
- トモズの別の店舗を足すときは、店舗ページのURL `https://shop.tomods.jp/detail/<番号>/` の番号を `shopId` に入れます
- GitHub Actions（`.github/workflows/deals.yml`）が毎日 6:00 と 18:00 に `scripts/fetch-deals.mjs` を実行し、結果を `deals.json` に保存します。Actions 画面の「Run workflow」で手動実行もできます
- 新しい形式のお店に対応するときは、`scripts/sources/` に読み取り方法を1つ追加して `index.mjs` に登録します
